Scientific Flowchart Symbology & Conventions (Standard ISO / ANSI Flowcharting)
Data In / Out (Parallelogram): User input files (CSV, Shapefiles) and intermediate analytical outputs (GeoTIFF, Arrays).

Process (Rectangle): Deterministic data transformations, clipping, tiling, and batch chunking.

Decision (Diamond): Analytical paradigm selection branching between continuous and discrete phylodynamics.
Terminal / Deliverable (Stadium): Primary biological inferences (Bayes factors, coefficient effect sizes, landscape evidence).
